## 🛠️ Technology Stack
- **Structure**: HTML5
- **Styling**: Vanilla CSS (Premium Glassmorphism Design)
- **Interactions**: Vanilla JavaScript & Lucide Icons
- **Form Handling**: Integrated with Formspree AJAX

## 📦 How to Use
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. Configure your Contact Form by updating the Formspree ID in `index.html` and `js/script.js`.
